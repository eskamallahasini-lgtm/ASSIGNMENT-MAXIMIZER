      How the Algorithm Works

      1. Each assignment is treated as an item.
      2. Assignment time is the weight.
      3. Expected marks are the value.
      4. Available student time is the knapsack capacity.
      5. Dynamic Programming calculates the maximum marks using dp[i][t] = max(dp[i-1][t], marks[i] + dp[i-1][t - time[i]]).
      6. Backtracking identifies the assignments that produced the optimal solution: starting at dp[n][T], if dp[i][t] != dp[i-1][t] assignment i was selected and t shrinks by its time.
      7. The result is displayed to the student.

      Time Complexity: O(n × T)   Space Complexity: O(n × T)
      n = number of assignments, T = available time

      Why 0/1 Knapsack?

      Choosing assignments is a real-world optimization problem. Each assignment has a time cost and an expected mark value, and the student has a limited time capacity. An assignment is either done fully or not at all, which is exactly the 0/1 restriction.

      Algorithm: 0/1 Knapsack + Dynamic Programming + Backtracking
      Time Complexity: O(n × T)   Space Complexity: O(n × T)
